1. [share.streamlit.io](https://share.streamlit.io)에 접속합니다.
2. **'Continue with GitHub'**를 눌러 GitHub 계정으로 로그인합니다.
  

  
1. 우측 상단의 **'Create app'** 또는 **'New app'** 버튼을 누릅니다.
2. `I already have an app`을 선택합니다.
3. 방금 코드를 올린 **GitHub Repository**, **Branch(main/master)**, **Main file path(`home.py`)**를 지정합니다.
4. **'Deploy!'** 버튼을 클릭합니다.
  

  
1. 1~2분 정도 기다리면 웹사이트가 열립니다.
2. 브라우저 주소창의 URL(`[https://광명기전-xxx.streamlit.app](https://광명기전-xxx.streamlit.app)`)을 복사하여 다른 사람에게 전달하거나 카카오톡/문자 등으로 공유하면 됩니다!
